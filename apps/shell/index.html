Silicon OS / Superintelligent OS

This is a live Phase 0 preview of the desktop chrome — not a working OS. Files, Keys, Calc, and Calendar are live, with a local data bus (e.g. Save to Files). Keys uses Web Crypto on-device only — not audited. No network calls from this shell.

  • Local-first by design (when modules ship)
  • Exportable data — no lock-in goal
  • MIT source on GitHub
